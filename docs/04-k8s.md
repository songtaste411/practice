# 第 4 层：K8s 骨架

这是清单，不是「打开就能用」的云。本机要先有 kubectl，并且集群里已经有这两个镜像：

- `prod-clinic-api:latest`
- `prod-clinic-web:latest`

Docker Desktop 自带的 Kubernetes 能看见本机 docker build 出来的镜像。别的集群要把镜像推进去。

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\k8s\ops.ps1 -Action up
powershell -ExecutionPolicy Bypass -File .\deploy\k8s\ops.ps1 -Action status
```

关掉并删掉这一套（里面的数据库也会没）：

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\k8s\ops.ps1 -Action down
```

Postgres 用的是空目录卷，Pod 一删数据就没。训练场这样够用。真要留数据，再加持久卷。

网页 Service 名字是 `web`，类型是 ClusterIP。临时从本机看页面：

```powershell
kubectl -n prod-clinic port-forward svc/web 18080:80
```

然后打开 http://localhost:18080 。
